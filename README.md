# 我的工作生活 APP（my-first）

一个**只供个人使用**的工作＋生活一体化管理网页应用：单个 HTML 文件、双击即用、数据保存在自己电脑的独立 JSON 文件里，不登录、不联网、不上云。

在线演示（GitHub Pages）：<https://xff38.github.io/my-first/>
（注意：网页版的数据存在浏览器本地；日常使用请下载 `我的工作生活APP.html` 双击运行并连接自己的数据文件。）

## 功能（9 个模块）

| 模块 | 功能 |
|---|---|
| 首页总览 | 今日计划摘要、快速备忘（Ctrl+N）、6 张模块摘要卡 |
| 今日计划 | 时间轴日程（拖拽改时间）、待办（未完成自动顺延）、每日回顾 |
| 自媒体 | 选题库、发布计划、平台数据手动录入与趋势图 |
| 开发工作 | 四列看板（拖拽换状态）、项目进展时间线 |
| 咨询工作 | 收入/收款记录、月度汇总与柱状图 |
| 学习计划 | 目标两层拆解、打卡热力图、周时间表、阅读清单 |
| 饮食计划 | 周餐食网格、三餐记录、菜谱库、体重趋势 |
| 游戏娱乐 | 娱乐时间记录、每周时段、"今天玩什么"随机抽选 |
| 数据与设置 | 数据文件连接/备份/恢复/导出、主题、平台与标签管理 |

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript（ES2020+），**零依赖、零网络请求**，全部内联进单个 HTML 文件；
- 数据持久化：File System Access API（`showOpenFilePicker` 读写用户选定的 JSON 数据文件）＋ localStorage 应急缓存（oplog 重放合并）；
- 图表为自研轻量 SVG 构建器（折线/柱状/热力格）；
- 构建/测试仅依赖 Node（无任何 npm 包）。

## 制作说明（构建 / 测试 / 使用）

1. **构建**：`node build.js`
   读取 `src/` 下模板、样式与按序脚本，内联合并输出 `我的工作生活APP.html` 与 `index.html`（两者内容一致；版本号可用环境变量 `APP_VERSION` 指定）。
2. **测试**：`node tests/run.js`
   108 例单元测试（工具函数、schema 清洗、oplog 合并、保存管道、顺延、图表、各模块业务流、构建产物结构），全部通过才可交付。
3. **本地使用**：双击 `我的工作生活APP.html`（Edge/Chrome）→ 首次在「数据与设置」点「新建数据文件」选位置 → 以后每次打开点「连接数据文件」授权一次 → 所有修改自动写入该 JSON 文件；「立即备份」生成带日期副本，「恢复…」可完整迁移。
4. **部署 GitHub Pages**：仓库根目录的 `index.html` 即站点首页；在仓库 Settings → Pages 选择 `main` 分支根目录（或 `gh api repos/<owner>/<repo>/pages -X POST -f build_type=legacy -f source[branch]=main -f "source[path]=/"`），推送后自动发布。
5. **开发约定**：需求变更先改 `PRD.md` 再改代码；每个里程碑补对应测试，测试不过不进入下一阶段。

## 已知环境限制

- 部分浏览器在 `file://` 下不提供 `showSaveFilePicker`/`showDirectoryPicker`，新建文件与备份自动降级为"下载＋引导连接"，数据安全性不变；
- 连接数据文件每次打开需点一次授权（浏览器安全规则）；
- 数据跟随"同一个浏览器"，换浏览器/换电脑请用备份文件恢复。
